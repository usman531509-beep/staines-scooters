`honda-forza.webp` is a locally optimised Honda Forza 125 product image from
[Honda UK](https://www.honda.co.uk/motorcycles/range/scooter/forza-125/overview.html).

through the existing WhatsApp details action.
Forza has been removed from the website catalogue; its original image is retained
as an unused source asset.

## Matching three-quarter catalogue images

`honda-vision-three-quarter.webp`, `honda-pcx-three-quarter.webp` and
`honda-sh-mode-three-quarter.webp` are AI-edited illustrations based on the respective
original fleet product images. The existing `yamaha-nmax.webp` supplied the common
right-facing front three-quarter camera angle, white studio background and soft
contact shadow. The edit brief preserves each original model's body shape, colour,
wheels and equipment. Original source files remain available alongside the new
versions. The shared scooter catalogue uses the new images for consistent appearance
across the homepage, rental page, sales page and details dialog.
